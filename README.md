
# 💰 Asisten Keuangan Mahasiswa CLI

Selamat datang di proyek kami!

**Asisten Keuangan Mahasiswa CLI** adalah aplikasi berbasis terminal (Command Line Interface) yang dibuat untuk membantu mahasiswa dalam mengelola keuangan sehari-hari dengan cara yang sederhana, cepat, dan praktis.


## ⚙️ Fitur Utama

Program ini memiliki beberapa fitur yang dirancang sesuai kebutuhan mahasiswa:

1. 🛒 **Kalkulator Diskon Belanja**  
   Menghitung harga akhir setelah diskon berdasarkan harga awal dan persentase diskon.

2. 🍽️ **Kalkulator Split Bill (Patungan)**  
   Menghitung jumlah yang harus dibayar setiap orang berdasarkan total tagihan dan jumlah orang.

3. 📈 **Kalkulator Bunga Tabungan Sederhana**  
   Menghitung total saldo setelah ditambahkan bunga bulanan.

4. 💸 **Kalkulator Sisa Uang Jajan Harian**  
   Menghitung sisa uang berdasarkan uang saku dan estimasi pengeluaran.

5. 🧩 **Antarmuka Menu Interaktif**  
   Tampilan menu utama yang memudahkan pengguna memilih fitur.
